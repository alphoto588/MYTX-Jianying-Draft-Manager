剪映草稿历史版本管理器

查询剪映 .backup 历史版本 · 网页可视化管理 · 一键安全恢复

🟢 零依赖 · 仅需 Python 3.8+ 🔒 恢复前自动备份 🖥️ 本地运行 · 数据不出机

✦这是什么

剪映专业版在编辑草稿时，会把每次自动保存的版本加密存放在草稿目录的 .backup/ 文件夹里。这个工具帮你：

📜
查询历史版本
扫描 .backup 目录，列出全部历史版本的时间、类型、大小与 MD5
🔍
自动发现根目录
扫描常见位置与各盘符；深度扫描可遍历盘符，兜底非常规位置
🗑️
回收站找回
自动列出剪映回收站中误删的草稿，可像正常草稿一样查看与恢复
👀
可视化对比
每个版本与当前版的体积差异一目了然，可按类型筛选
⚡
一键恢复
点击按钮即把任意历史版本恢复为当前草稿，全程自动备份
🛡️
安全防护
剪映运行时自动锁定、恢复前强制快照、防路径穿越
🧹
备份清理
一键清理过旧的自动保存备份，保留最近 N 个，回收空间
↩️
随时回退
每次恢复前都会生成"恢复快照"，反悔了再恢复它即可

1启动方式

方式一（推荐）：进入工具目录，双击 start.bat，浏览器会自动提示访问地址。

方式二（命令行）：

# 默认端口 8620
python app.py

# 指定端口
python app.py --port 9000

启动成功后，用浏览器打开：

http://127.0.0.1:8620
💡 提示：工具无需安装任何第三方库；stop 服务在命令行按 Ctrl + C 即可。

2使用流程

1
确认剪映已关闭
查看页面右上角状态徽章，显示"剪映未运行 · 可安全恢复"才能执行恢复。如显示运行中，请先完全关闭剪映（包括托盘进程）。
2
定位草稿根目录
页面加载时会自动发现；如草稿在非常规位置，点击「🔍 自动发现」扫描常见位置与各盘符，或「🔎 深度扫描」遍历盘符兜底，点击结果即可扫描。
3
选择草稿项目
点击草稿卡片，查看当前版本信息（大小 / 修改时间 / MD5）与完整的历史版本列表。
4
恢复目标版本
在列表中找到想要的版本，点击「恢复此版本」并在弹窗中确认。随后重新打开剪映即可加载。
版本类型图例： 自动保存 关闭备份 打开备份 恢复快照 上一版本 当前版本

3恢复与回退

点击「恢复此版本」时，工具会按顺序自动完成三件事：

步骤动作说明
①检测剪映进程运行中则拒绝操作，防止写入冲突
②备份当前草稿生成 YYYYMMDDHHMMSS_restore_<md5>.save.bak 快照
③覆盖草稿文件用所选历史版本写入 draft_content.json
↩️ 回退方法：每次恢复前生成的"恢复快照"也会出现在版本列表中（紫色标签）。对结果不满意时，找到该快照再次点击「恢复此版本」即可完全回到操作前状态。
🗑 删除版本：每行操作列的「删除」按钮可直接删掉不需要的历史版本。删除不可逆、不进回收站，弹窗会显示该版本的类型/时间/大小供确认；删除"恢复快照"会同时放弃对应的回退机会。

5注意事项

⛔ 恢复操作务必在剪映完全关闭时进行——包括系统托盘中的剪映进程。工具检测到剪映运行时会自动拒绝恢复，这是防止草稿被覆盖写入的保护机制。
🔐 关于加密：剪映草稿内容为加密存储，本工具只做文件级版本管理，不涉及解密；解密由剪映读取 draft_content.json 时通过 crypto_key_store.dat 自动完成。
🔄 打开后缓存刷新：恢复后打开剪映，草稿的封面、时长等缓存信息会自动刷新，短暂显示旧信息属正常现象。
🧹 清理备份：版本列表右上角的「清理旧备份」按钮可清理过旧的自动保存（保留最近 N 个），清理只删除 自动保存 类型，不会动关闭/打开备份、恢复快照和当前版本。

?常见问题

找不到草稿根目录怎么办？
点击「🔍 自动发现」会扫描常见位置（用户目录、各盘符根等）；仍找不到时用「🔎 深度扫描」遍历各盘符（限深 5 层、跳过系统目录，通常 1 分钟内）。发现的结果会以卡片形式列出，点击即扫描。
误删的草稿能找回吗？
能。剪映删除草稿时会移入根目录下的 .recycle_bin 回收站。扫描草稿后，列表底部会显示带 🗑 标记的回收站草稿，可以查看其历史版本并恢复；确认无误后把草稿文件夹移出 .recycle_bin（或在剪映中还原）即可正常打开。
为什么点击「恢复此版本」没有反应？
页面右上角显示"剪映运行中 · 已锁定恢复"时，所有恢复操作都会被禁止。请先完全关闭剪映（含托盘进程），状态变为绿色后重试。
恢复后打开剪映，内容不对怎么办？
先关闭剪映，回到工具中找到刚才生成的「恢复快照」（紫色标签），再次点击恢复即可回到操作前的草稿状态。
历史版本体积差了几十倍，哪个是完整的？
"上一版本"（draft_content.json.bak）和体积最大的「自动保存」版本通常内容最全。列表中每个版本都标注了与当前版的差异百分比，可作为参考。
可以管理其他电脑上的草稿吗？
可以。在「扫描草稿」输入框中填写任意包含草稿的目录路径（草稿目录的标志是含有 draft_content.json 的文件夹），点击扫描即可。
端口被占用怎么办？
用命令行方式启动并换一个端口，例如 python app.py --port 9000，然后访问 http://127.0.0.1:9000。
